Datasets

A dataset version is a frozen copy of the export: its frames, labels, splits and class list, with a hash. Models are trained on a version, never on "the export as it is today", so a result can be repeated. Versions are numbered and never changed. A new version keeps every site-and-date group in the split it had before, so the test set stays the same; only new groups are dealt (about 70 / 20 / 10). In {{ info.folder }}/datasets/.
